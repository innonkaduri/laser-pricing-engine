# מנוע תמחור לייזר

מערכת עצמאית לתמחור חיתוך לייזר לעסק המתכת המשפחתי. זורקים קובץ ייצור
(DXF) או מזינים ידנית, המערכת מחלצת פרמטרים ומציגה ממשק אינטראקטיבי עם
הדמיה וטבלה.

**נפרדת לחלוטין מה-CRM. אין שום חיבור ביניהם.**

## שלושת הכללים שמעצבים את הקוד

1. **הטבלה של ינון היא מקור האמת היחיד למחיר.** המנוע מחשב *כמה* יחידות
   של כל דבר צריך — לא *מה מחירן*. צירוף חומר+עובי שאינו בטבלה גורם
   לשגיאה מפורשת, לא לניחוש ולא ל"ברירת מחדל סבירה".
2. **אילוץ הפלטה הוא הבדיקה הבינארית היחידה.** חלק שחורג מ-3000x1500
   אינו ניתן לייצור — זו אי-אפשרות טכנית, לא שאלת מחיר. נחסם לפני כל
   חישוב כספי.
3. **כל השאר רציף ומדורג.** ניצולת, בזבוז ומחיר נעים ברציפות. אין
   "נכנס / לא נכנס".

## חיסכון הטוקנים

חילוץ המידות נעשה מקומית ב-ezdxf. קובץ ה-DXF **לעולם לא נשלח למודל**.
מה שנשלח הוא `Part.summary()` — כ-50 טוקנים:

```json
{"name":"תושבת","material":"st37","thickness_mm":3.0,"quantity":25,
 "width_mm":400.0,"height_mm":250.0,"net_area_mm2":98036.74,
 "cut_length_mm":1457.09,"pierces":2,"holes":1,"bodies":1,"source":"dxf"}
```

## הרצה

```bash
uv sync
uv run pytest                                    # 78 בדיקות
uv run uvicorn main:app --reload --port 8000     # ממשק ב-http://localhost:8000
```

## פריסה

```bash
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port $PORT
```

| משתנה סביבה | תפקיד |
|---|---|
| `TARIFF_JSON` | טבלת התמחור כמחרוזת JSON. **זה מה ששורד פריסה מחדש** — כתיבה לדיסק בתוכנית חינמית נמחקת. |
| `TARIFF_PATH` | נתיב חלופי לקובץ הטבלה. |
| `APP_PASSWORD` | מדליק שער סיסמה. בלעדיו הכתובת פתוחה לכל אחד — כולל עריכת המחירים. |
| `APP_USER` | שם המשתמש לשער. ברירת מחדל `ynon`. |

## טבלת התמחור

`config/tariff.example.json` היא התבנית. **כל המחירים בה 0 בכוונה** —
היא מבנה, לא מחירון. ינון ממלא את הערכים בפועל.
