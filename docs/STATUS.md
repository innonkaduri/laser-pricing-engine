# STATUS — מנוע תמחור לייזר
Updated: 2026-08-11 · session: הסשן המרכזי

## Now
המערכת חיה בענן. שכבת API + ממשק אינטראקטיבי מעל הליבה החישובית:
DXF או קלט ידני → גיאומטריה → אילוץ פלטה → נסטינג → בזבוז מדורג →
הצעת מחיר מפורטת + הדמיית פריסה. 78 בדיקות עוברות.

## מה קיים
- **`domain/`** — `Contour` / `BoundingBox` / `PartGeometry` / `Part`.
  שטח נטו, אורך חיתוך, ניקובים, סיווג חיצוני-מול-חורים. כל מקורות הקלט
  (DXF, ידני, תלת-ממד) נשפכים לאותם טיפוסים.
- **`cad/dxf_reader.py`** — ezdxf. משחזר מתארים סגורים מקווים נפרדים
  (`edgeminer`), שומר עקמומיות קשתות, ממיר יחידות לפי `$INSUNITS`,
  מפוצץ בלוקים, מסנן טקסט ושכבות מידות.
- **`nesting/`** — פלטה 3000x1500 (שוליים 20 מ"מ, פרמטרי), אילוץ קשיח,
  MaxRects/BSSF עם סיבוב, ניצולת רציפה, חילוץ שאריות זרות ודירוגן.
- **`pricing/`** — `Tariff` (הטבלה של ינון) + `engine`. קיבוץ לפי
  חומר+עובי, מדרגות בזבוז, מינימומים, מרווח, מע"מ, פירוט מלא לשורה.
- **`api/`** — FastAPI. העלאת DXF, קלט ידני, תמחור, קריאה ועריכה של
  הטבלה, ושער סיסמה שנדלק כשמוגדר `APP_PASSWORD`.
- **`web/`** — ממשק עברית RTL: תצוגה מקדימה של כל חלק, בחירת חומר/עובי,
  טבלת הצעה מפורטת, הדמיית פריסה על הפלטה, ועורך הטבלה.
- **`config/tariff.example.json`** — תבנית הטבלה. כל המחירים 0 בכוונה.

## פריסה
- `main.py` מוסיף את `src/` לנתיב, ולכן אותה פקודת הרצה עובדת מקומית
  ובענן: `uvicorn main:app --host 0.0.0.0 --port $PORT`.
- `render.yaml` — שירות web, אזור פרנקפורט, `healthCheckPath: /health`.
- **`TARIFF_JSON`** הוא מה ששורד פריסה מחדש. כתיבה לדיסק בתוכנית
  החינמית נמחקת בכל הפעלה מחדש, ולכן הממשק אומר את זה במפורש אחרי
  כל שמירה ומציע להוריד את הקובץ.
- **`APP_PASSWORD`** — בלעדיו הכתובת פתוחה לכל אחד, כולל `PUT` על
  טבלת התמחור. השער חל על הכל חוץ מ-`/health`.

## באגים שנתפסו בבדיקות (ולא הגיעו הלאה)
- רמפת איכות השארית הייתה קוד מת — סף השטח שווה לריבוע הצד הקצר.
- אחוז הבזבוז חושב מול הפלטה המלאה, ולכן **עלה** ככל שהוזמנו יותר
  חלקים — הפוך מהנכון.
- זיכוי לפי המלבן הפנוי הגדול ביותר בלבד גרם לבזבוז להתנדנד: 3 חלקים
  יצאו יקרים יותר מ-2. תוקן בחילוץ שאריות זרות זו לזו.
- `max_credit_ratio` לא הוחל על חישוב הבזבוז עצמו, רק על שדה תצוגה.
- בדיקות ה-API כתבו את `config/tariff.json` האמיתי בריפו, כי הטבלה
  הפעילה היא מצב גלובלי של התהליך. נחסם בפיקסצ'ר בידוד.
