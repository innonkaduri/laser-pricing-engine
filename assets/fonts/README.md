# גופנים לחיתוך

**Assistant** מאת Ben Nathan, ברישיון **SIL OFL 1.1** (`OFL.txt`).
נלקח מ-Google Fonts, ומכסה את האלף-בית העברי המלא כולל אותיות
סופיות, לטינית וספרות.

- `assistant-400.ttf`, `assistant-700.ttf` — המקור.
- `glyphs.json` — **מה שהשרת קורא בפועל.** נוצר מהמקור על ידי
  `scripts/build-glyphs.py`, ומכיל את **האיחוד** של הצורות שכל אות
  מורכבת מהן. גופן מצייר אות בכמה מצולעים חופפים ונשען על מילוי
  non-zero; חיתוך שלהם כמו שהם היה חורץ קווים בתוך האות.

**אחרי כל שינוי בגופן או ברשימת התווים — להריץ מחדש ולקמט:**

    .venv/bin/python scripts/build-glyphs.py

הבנייה לוקחת כחצי דקה ואינה רצה בשרת: הקופסה היא שתי ליבות
המשותפות לחמישה פרויקטים, ורסטור בדיוק גבוה על כל הקלדה בעורך הוא
בדיוק העיבוד הכבד שאסור שם.
